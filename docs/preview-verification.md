# Visual verification

The current distributable example is the English-language Flutter host app. The early HTML concept under the former working name has been retired from the current tree; its historical source remains in Git history. It is not a second assistant or a supported runtime example.

Flutter widget tests cover narrow/wide containers, keyboard insets, enlarged text, permissions and tool completion. Browser checks exercise the actual Flutter web example at desktop and mobile viewport widths. Screenshots in this directory show the running implementation, not a hosted AI service.

The demo uses simulated model responses and a real in-memory local tool. Visual verification does not establish provider compatibility, production authorization or a complete accessibility audit.
